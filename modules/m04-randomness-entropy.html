Randomness & Entropy

You can build a bank vault out of 10-foot-thick solid titanium, but if you lock it with a cheap 3-digit combination padlock, the titanium is useless. Randomness is the fuel of all secrets.

1. What is Entropy?

In cryptography, entropy measures unpredictability or pure surprise.

If you tell an attacker: "My password is a day of the week," your entropy is tiny (only 7 choices). An attacker checks all 7 in 0.0001 seconds.

If you use a 256-bit random key, there are $2^{256}$ possible combinations. That number is larger than the total number of atoms in the entire observable universe. Even if all computers on Earth combined to guess a billion keys per second, the sun would burn out long before they guessed it.

2. The Trap: PRNG vs. True Hardware Chaos

Computers are deterministic calculators. When you tell a computer to "pick a random number," it usually runs an equation starting from a seed (like the current microsecond clock).

3. Historic Disasters: When Randomness Failed

When cryptography breaks in the real world, it is almost never because someone cracked the mathematical equations; it is because the random number generator was predictable:

Case Study: The Sony PlayStation 3 Master Key

In 2010, hackers extracted Sony's master private signing key. Sony's engineers implemented ECDSA (Elliptic Curve Digital Signature Algorithm)—a mathematically unbreakable signature. But ECDSA requires a fresh random number (a nonce) for every signature. Sony's code accidentally reused the same fixed number every time! Within hours, researchers extracted the root key using high school algebra.
